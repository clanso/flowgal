# 逆转式立绘动画：眨眼、口型的节奏和做法（含侧身立绘）

2026-10-10 整理。目的：给 FlowGal 的「逆转式动态立绘」定一套有依据的帧表和节奏，并做出能用 NovelAI 局部重绘批量生产的工作流。

## 1. 原作怎么组织一个立绘动作

粉丝社区（Attorney Online、objection.lol、Court Records 的拆包）的一致做法，和原作拆出来的动图对得上：

| 文件 | 作用 | 播放方式 |
|---|---|---|
| `xxx(a).gif` | 待机：静止姿势 + 偶尔眨眼 | 循环 |
| `xxx(b).gif` | 说话：同一姿势 + 嘴开合（中途也会眨眼） | 出字时循环，字停就换回 (a) |
| `xxx.gif`（不带后缀） | 前置动作（拍桌、耸肩、点头、摇头、转身） | 说这句之前播一次，播完才出字 |
| `xxx(c).gif` | 过渡（比如从侧身转回来、说完收回到待机） | 播一次 |

DS 原作里眼睛、嘴是**换贴片**而不是整张重画（拆包的人说原作「只换眼睛，不换整张」）。HD 重制按原像素画的帧数一张张重画，少数地方补了中间帧。

## 2. 实测：原作每帧停多久

在浏览器里逐帧解码 Court Records 的原版动图（只读、没下载到本地），按「哪几帧画面相同」合并后的时长（毫秒）：

**待机眨眼**
- 御剑：半闭 100 → 闭 100 → 半闭 100，两次之间 1660 / 3330 / 4000
- 成步堂：半闭 60 → 闭 60 → 半闭 60（另一次 50/50/50），间隔 1660
- 真宵：150/150/150 和 100/100/100 两种，间隔 410～2000
- 拉米洛亚侧身：160/160/160，间隔 2000～2500

**说话**
- 御剑：闭 → 张 → 半 → 张 → 闭……每帧 160；说话中途眨眼，眨眼帧 80/80/100
- 成步堂：每帧 130；真宵：每帧 150
- 都是 3 种嘴形（闭、半、张），4 步一循环

**动作（前置动画）**——时长很不均匀，「关键姿势停得久、过渡帧一闪而过」：
- 成步堂摇头：60 → 100 → 130 → 110 → **200**（最左）→ 110 → **250**（最右）→ 100 → 160
- 王泥喜摇头：60 → 130 → 250 → 250 → 110 → 250 → 110 → 250 → 100 → **眨眼 100** → 160
- 真宵点头：250 → 100（预备）→ **410** → 60（快速低头）→ 130 → 110 → **660**（落定）
- 拉娜转身：正面 **500** → 3/4 侧脸 **330** → 背面（只有 1 张中间帧）
- 御剑耸肩：330/330/250/200/100/200/100/250/500

**看帧图得出的规律**
- 摇头、点头、转身的中间帧**全部闭眼**：第一帧（60～130ms）就闭眼，头转过去、转回来全程闭着，最后才睁开，有时还补一次眨眼。闭眼把「换了一张脸」的跳变藏住了。
- 转身只画 1 张中间帧（3/4 侧脸 + 闭眼），配合停顿就够了。

## 3. 别人分享的节奏经验

**人眼眨眼**（生理学文献）：闭眼约 80ms、睁眼约 180ms（闭得快、睁得慢，睁的后半段是慢慢收尾），全闭约 50ms，一次 100～400ms；静止时约 17 次/分钟（平均 3.5 秒一次），聊天时更频繁，读字时更少。

**Live2D**：默认间隔约 4 秒（0～2 倍随机），闭 0.1 秒 / 停 0.05 秒 / 睁 0.15 秒；VTuber 建议说话时少眨。

**Ren'Py 社区**：随机间隔（2～5 秒或 4～12 秒），偶尔连眨两下（插件里常设约 20%），从不连眨三下；嘴只在出字时动，字一停马上闭。

**日本动画（作画经验）**
- 目パチ：开 → 中 → 闭 →（中）→ 开；中间那张偏向开眼一侧画；眼角位置开闭要对齐；闭眼约 1/8 秒。
- 口パク：闭、中、开三张，**要乱序出现**——只在开和中之间来回切，看起来像嘴张着在抖；一个字占 2～4 格（24 格/秒，约 80～170ms），4 格以上会显得卡。
- 高品质作品用 6 种嘴形。

**口型同步工具 Rhubarb**：6 个基本嘴形（A 闭/双唇音、B 齿缝/大多数辅音和 i、C 开/e、D 大开/a、E 圆/o、F 嘟/u），可选 G（f/v）、H（l）、X（放松闭嘴）。这是从汉纳-巴伯拉动画沿用下来的行业标准。

## 4. 由此定下的新版规则（lib/aa-motion.js）

**素材**：一张整图（头部不动），眼睛 2 态（半闭、闭）、嘴 4 态（齿缝、小开、开、圆）是贴在整图上的贴片。要侧身就另画一张侧身立绘、单独做一套（见第 5 节），不做转头动画。

**眨眼**：半闭 40 → 闭 70 → 半闭 90（闭得快、睁得慢，跟原作一样只用半闭、闭两张）；间隔 2.2～5.6 秒随机；句末标点后 50% 眨一下，开口时 30% 眨一下。
- **连眨两下**（18%）：半闭 40 → 闭 70 → 半闭 60 → 闭 56 → 半闭 90，共约 0.3 秒。两下之间只睁到半闭、停 60ms 就再闭，第二下闭得短一点，最后照常慢慢睁开。最早的写法是「眨完一次、半闭停 110ms、再眨一次」，两下之间在半闭上停了 240ms，看着像困得睁不开眼。

**嘴**
- 一句话先按标点和长停顿切成「气口」，气口之间闭嘴。
- 气口里打「音节拍子」：拍子永远落在某个字出现的那一刻；一拍至少 95ms，字慢时一字一拍（威压）。默认 30ms 一字时约 4 个字一拍（120ms），接近原作的 130～160ms。
- 每拍前 60% 开口到这拍第一个字的嘴形，后 40% 收到小一号（开→小开、小开/圆→齿缝、齿缝→闭）。
- 嘴形由字的韵母定：a→小开（喊时开）、e→小开、i→齿缝、o/u→圆；假名、拉丁字母按元音对；汉字没有读音表，按字算固定的类（同一个字永远同一个嘴形，比例照普通话韵母分布）。
- 连着同一嘴形就换用别的（防「原地抖」）；和上一拍收口撞了就换相邻嘴形（保证每拍都看得见一动）。
- 演法：低语只用齿缝；怒吼、崩溃、威压用大一号；重音字大一号。

**试过又删掉的**：转头动画（先闭眼 → 中间帧 → 到侧头再睁眼，照原作摇头、转身的做法）。做得出来，但驾驶员觉得头部保持不动更好，删了。

## 5. 用 NovelAI 做素材的办法

全部用 NovelAI V5（实测 0 Anlas，但会消耗「V5 额度指标」这个会慢慢回满的池子，约 6～8 张掉 1%、约 100 分钟回 1%）。

- **透明底**：请求带 `tag_hint_transparent_background` + `straight_alpha`，送带透明度的原图，回来的图自带透明度。
- **原生侧身立绘**：拿正面立绘的同一份请求（画师串、人物描述、种子、参数），把 Base 和角色块里的 `facing viewer / looking at viewer / straight-on / facing forward / eye-level` 换成 `from side, profile, looking to the side`，负面里去掉 `side view / from side / profile`，整张重新生成。发色、和服、羽织、袴都对得上；换种子时发色可能偏黄，原图的种子最稳。之后照常做眼嘴差分。
- **重绘强度不起作用**：V5 局部重绘不认 `inpaintImg2ImgStrength`，0.35～0.65 回来的图和 1.0 逐像素一样（最大差 1）。框里一律整块重画，只是会参照框里原来的图。
- **「略垂」（睁四分之三）做不出来**：从睁眼图出发也一下就画成半闭；叠图做的又是一张画法略不同的半闭眼，眨眼时在两张半闭眼之间跳，看着像抖。所以只用半闭、闭。
- **眼睛贴片要「清洗」**（每张都做，打包时自动）：
  - 颜色对齐：重画的半闭眼虹膜常比原图深、蓝（实测浅灰蓝 190/203/221 → 深蓝 130/148/167，饱和 35 → 60），眼框里的皮肤也偏暗，眨眼时眼睛会闪色、眼周会闪出方块。只留和原图色差大的像素（眼皮、睫毛、眼线），其余用原图；先按没变的皮肤补整体偏色，再把虹膜（有彩度的蓝）、线条（暗）分别按 Lab 均值方差拉到原图同类的颜色。
  - 只改眼睛本身（眼核）：眼框里压着的刘海、两眼之间的头发、眉毛、腮红每次也会被重画几笔，半闭、闭各画各的，眨眼时头发跟着跳。按颜色认头发不可靠（有的角色发色跟皮肤、腮红几乎一样），改按位置：原图和重画里成块的眼白、虹膜取凸包，往上撑到上睫毛（0.7 个眼高，不超过 0.22 个眼宽）、往下 0.35 个眼高、两边 0.12 个眼宽，再加上挨着它们的成块大变化（虹膜变成眼皮那一大块；一两像素宽的细线是头发描边挪了位置，不算）。眼核外面一律用原图。眼睛几乎被头发全挡住、认不出眼核时，退回只许改眼框的内切椭圆。压在眼睛正中的头发在眼核里，仍会跟着重画。
  - 嘴只补整体偏色、不分类（嘴里的暗红不能拉成睫毛色）。
- **嘴**：照 v3「扁长框」——重画框的形状就是嘴能长多大。框至少要盖住原来整条闭嘴线（窄了线头会留在两边），只调高度：齿缝 / 小开 / 开用 40×16，圆用 40×24。不要加 `small mouth`（会画成一个点）。
  - NovelAI 会把嘴画在遮罩中间：框对齐 8 像素后框心跟嘴线差几像素，嘴就偏几像素；框上面空得多，张嘴就往上长（实测上沿高出嘴线 8 像素）。所以生成前先在框里找原来的嘴线（比肤色暗或更红、不碰框边，断开的几段合起来），框左右对准嘴线中心、上边收到嘴线上方 2 像素、下边不动。
  - 洗贴片时再把新画的嘴挪回嘴线：左右按中心对齐；小开、开的上沿不高过嘴线 1 像素（只往下挪），齿缝、圆按中心对齐；最多挪 6 像素，挪完旧嘴线必须还在新画的那块里。只改旧嘴线和新嘴附近，下巴、衣领被重画了几笔也用原图。侧脸的嘴贴着轮廓，圆嘴的高框会压到下巴和手、画出黑斑；侧脸也画不好「o」形，所以侧身立绘的「圆」用一张开口小的齿缝嘴代替。
- 每个状态出 2 个种子，贴回原图放大对照挑选；长得更像别的嘴形的候选可以直接存成那个嘴形。

## 6. 在 FlowGal 里怎么用

- **逆转式工作台**照第 5 节做：每张差分 6 次局部重绘（精简版 2 次：闭眼、小开），重画结果在浏览器里洗成贴片（`lib/aa-patch.js`；颜色对齐那几步跟 Python 原型逐像素对过，眼核、嘴对齐只在这里），拼成 v2 素材包。
- **精简版**（路人省额度）：只有闭眼和一个张嘴。播的时候自己适配（`lib/aa-motion.js` 的 `fitBlink` / `fitTalk`）：眨眼是睁 → 闭 110ms → 睁，连眨两下中间完全睁开 70ms；所有嘴形都落到那一个张嘴上，收口一律闭嘴，变成两帧开合。
- **原生侧身立绘**：「侧身」动作组（默认放赌气）。这一组的底图整张按侧身构图画（`image/style.js`：Base 和角色块的「正面、看镜头」换成 `from side, profile, looking to the side`，负面拿掉侧身的词、加上 `looking at viewer`），同组其余情绪在它上面只换脸，再用工作台做眨眼和口型。
