# FlowGal · DSH Tavern 视觉小说插件

把 [DSH Tavern](https://github.com/flizzywine/dsh-tavern) 的聊天变成一部会自己排版、配图、配乐的视觉小说。

**正文先出，演出后到。** Tavern 照常流式输出正文，你可以立刻读；这一轮写完后，插件在后台让一个「导演」模型把正文整理成场景脚本：哪些是故事、哪些是状态栏和装饰，谁在说话、什么表情、站在哪、谁在哪一句登场退场、镜头怎么走、这一幕放哪首曲子、哪个瞬间值得画成 CG、给你几个选项。要画的瞬间再交给「插画分镜师」，按柏宝绘的分人写法写成生图提示词。整理好之前剧场就能按原文先演，整理好后画面会原地更新。

## 安装

需要 DSH Tavern（插件接口 v1，`dsh >=0.1.0-rc.8`）和 git。下面的命令都在 **DSH 终端**里执行（DSH 设置 → 通用设置 →「打开 DSH 终端」），Tavern 用的 profile 叫 `tavern`。

```sh
cd ~
git clone https://github.com/clanso/flowgal.git
dsh plugin --profile tavern add "$HOME/flowgal"
```

Windows 的终端是 cmd 时不认 `$HOME`，最后一条写完整路径，比如 `dsh plugin --profile tavern add "C:\Users\你的用户名\flowgal"`。

然后**完全退出 DSH 再打开**（只刷新网页不够，插件的后台部分要重启才加载），刷新 Tavern 页面。

- 插件是按文件夹链接进去的，`flowgal` 文件夹装好后不要移动或删除；以后的更新也在这个文件夹里进行。
- 卸载：`dsh plugin --profile tavern remove flowgal`，重启 DSH。插件的数据在 `$DSH_HOME/flowgal/`（默认 `~/.dsh/flowgal/`），不要了可以整个删掉。

仓库里已经带了构建好的 `client.js`，不需要自己打包。改了 `src/client/` 之后再重建：

```sh
cd flowgal
npm install
npm run build     # 生成 client.js
npm test
```

装好后，Tavern 侧栏底部会多一个「🎬 FlowGal」按钮；设置 → 插件里有一张简版设置卡，完整设置在剧场里的 CONFIG。

### 更新

按上面的方法用 git clone 装的，可以直接在剧场里更新：设置 → 版本与更新 →「检查更新」→「立即更新」，然后重启 DSH 并刷新网页。有新版本时标题画面也会出现「更新插件」。

- 更新只做快进（相当于 `git pull --ff-only`），本地改过的文件不会被覆盖；有冲突、或者本地有没推送的提交时会停下来，把原因写在页面上。
- 跟踪的分支在远端被删了时，可以一键改跟 `main`；`main` 上还没有插件时不会切。
- 打开剧场时会顺便检查一次（最多 12 小时一次），可以在同一页关掉。
- 不是 git 克隆的装法（压缩包、npm）没法在页面里更新：先 `dsh plugin --profile tavern remove flowgal`，再按上面的「安装」用 git clone 装一次。

## 在聊天里

- **场景卡**：每轮正文下方一张卡，显示地点、时段、天气、场景基调、在场人物和选项数，按钮是「进入剧场 / 人物志 / 重新整理」。导演还没整理完时显示「导演正在整理这一幕」和「先看起来」。
- **插画卡**：导演决定这一轮值得一张 CG 时，CG 直接插在对应段落下面。悬停出现工具条：切换历史版本、重画、改词，点图放大。
- **消息按钮**：每条回复上有「🎬 剧场」（从这一轮开始看）和「🖼 配一张」（让导演为这一轮补一张 CG）。
- **补图**：场景卡上的「补图」把这一轮错过的插画、背景、立绘差分补上，见下面的[补图](#补图)。
- 想让剧场在每轮写完后自动弹出，打开设置里的「写完自动打开剧场」。

## 我的配乐

FlowGal 不自带音乐，放的都是你自己的曲子。设置 → 配乐：

- **导入文件夹**：选整个音乐文件夹，里面的 mp3 / m4a / aac / ogg / opus / wav / flac 会逐首存进插件（单首最大 50 MB，最多 300 首）。同一首再导入不会重复存。也可以用「添加曲子」挑几首。
- **每首写一段描述和几个标签**，完全自由：听感、乐器、适合什么场面、什么情绪，怎么写都行。比如「慢速合成器和雨声，深夜独处、心事重重，也适合告白前的沉默」。
- **导演自己选曲**：后台导演整理每一轮时会读到整张曲目表（编号、曲名、描述、标签），自己决定这一幕放哪首、上一首还合不合适、要不要留白不放；剧情中途情绪转折时还可以从某一句开始换歌（一轮最多换一次）。选曲结果在导演日志的「整理结果」里能看到。
- 导演还没整理到的轮次，剧场先按描述粗配一首（描述和标签里出现场景的情绪、时段、天气、地点词越多越优先），整理好后换成导演选的。
- **描述文件** `flowgal-music.json`：「导出描述」会下载一份，放进音乐文件夹后，下次导入文件夹时会按文件名自动带上曲名、描述和标签（以这个文件为准）。格式：

  ```json
  {
    "format": "flowgal-music",
    "version": 1,
    "tracks": [
      { "file": "14 Neon Rain.mp3", "name": "Neon Rain", "description": "慢速，雨夜霓虹……", "tags": ["雨", "夜", "感伤"] }
    ]
  }
  ```

- 试听时剧场的配乐会先淡下去；音量和总开关也在这一页。曲子只存在 `$DSH_HOME/flowgal/assets/`，不会上传到任何地方。

## 导演日志

后台导演不是黑箱。剧场右上角的「导演整理中 ›」、快捷栏的 DIR、标题菜单、设置 → 导演，以及聊天里场景卡上的「看导演在写什么」都能打开导演日志：

- **实时输出**：导演整理时，模型吐出的每个字（和它的思考过程，模型支持的话）实时滚动；觉得跑偏了可以直接「停止整理」，这一轮先按原文演。
- **整理结果**：解析后的场景（地点、时段、天气、基调、配乐、转场、背景提示词）、站位，以及**逐句**标注：每个正文单元被判成谁在说、什么表情、弹什么漫画符号、用什么镜头、是不是卡片、谁登场谁退场、从哪句换歌；还有选项、挑中要画的瞬间（从哪句显示到哪句）和外貌档案的改动。
- **插画分镜师和立绘设计师**也各有记录（「插画 · 第 N 轮」「立绘 · 名字」）：读了多少资料和剧情、实时输出，以及写出的每一份提示词。
- **原始输出**：每次请求的原文、用时、最大输出、用量（输入 / 输出 / 思考 token），解析失败或被模型拒绝的报错，以及插件为什么重试。
- **提示词**：实际发给模型的系统提示词和用户消息全文，可以一键复制去别处调试。
- 每局保留最近 30 次记录，单独存在 `games/<局>.director.json`，删局时一起删。

最大输出默认 128000、资料长度默认 1000000 字（按当前主流大模型的输出上限和上下文量级）。插件会问 DSH 这个模型的上下文窗口：资料太长就自动缩短，输入加最大输出装不下就把最大输出往下收；模型仍然拒绝这个最大输出时，按它报错里给的上限重试一次。每次实际用了多少都写在导演日志里。

## 只演故事本身

很多角色卡会让模型在正文里夹带状态栏、变量更新、思考过程、花边和章节尾巴，有的干脆让它写一整个网页。这些都不该搬上舞台：

- **切单元之前先剥一遍**：思考过程、变量更新（`<UpdateVariable>`）、网页的头部、导航、页脚、按钮，以及代码块标记、分隔线和 Markdown 记号都去掉。模型写的是 HTML 时按网页结构拆开：段落、表格的格子、定义列表里的「名字 / 台词」不会粘成一团。原文里的 {{user}}、{{char}} 换成名字；有别的宏，或者 Tavern 的正则藏掉了一部分时，就跟 Tavern 给插件的正文走。
- **拿不准的交给导演**：状态栏、属性面板、目录、简介框、作者的话、下一章预告、选项菜单……导演把这些单元标成「不演」。正文本身是一篇文档时（比如一个 wiki 样式的页面，主体是某个游戏的回想剧本），导演先找出主体，只演剧本里的旁白和台词，页面上其余的都不演；剧本里没加引号的台词、括号里的舞台指示，导演会改判成台词或旁白。状态栏里的时间、地点、穿着照样用来判断场景和人物，选项菜单里的选项改写成剧场末尾的选项。拿不准是不是故事的照演。
- 剧场、鉴赏里「剧场里显示」的可选句子、插画分镜师和立绘设计师读的剧情，都只有要演的部分。导演日志的逐句标注里，不演的单元划掉显示。
- 切单元也认得剧本常见的写法：「林岚：台词」「【林岚】台词」、表格里「林岚 | 台词」的一行；「林岚说：“……”」这种引号前只有名字的，不再把「林岚说：」单独演成一句旁白（名牌上已经有名字了）。「时间：19:40 ｜ 地点：屋檐下」这样一行几项的状态栏不会被当成「时间」在说话。

## 剧场

- **舞台**：背景优先用 AI 为这个地点生成的背景，没有时用程序绘制的天空与天际线；时段和天气会给画面调色；转场有溶解、电影黑边、横扫、圆形收缩、百叶、黑场、白闪几种。
- **CG 什么时候出现、什么时候收起**：导演挑插画时同时定好它在剧场里从哪一句显示到哪一句。到了起始那一句，插画从左往右揭开、盖满舞台；画里的那个瞬间演完（有人离开或进来、动作换了、场面转到别处），从下一句起插画淡出，露出背景和立绘。导演没写收在哪一句就显示到这一轮结束。鉴赏的「改词」里可以自己改显示到哪一句，不用重画。聊天里插画挂在那一句后面，不受影响。
- **CG 怎么动**：横版插画缓慢推拉；**竖版插画**铺满宽度，先停在顶上，再慢慢摇到底，然后拉远露出整张图（两侧垫着同一张图的模糊版），再倒着放回来，越长的图摇得越久。系统设了「减少动态效果」时直接显示整张。
- **立绘什么时候出现、什么时候消失**：导演在 cast 里列出这一轮会出场的人，并在正文里标出谁在哪一句登场、哪一句离开：推门进来、从远处跑过来的人到那一句才从靠近的一侧滑进来（站在中间的人原地浮现）；转身走了、被拉走的人在那一句往同一侧淡出，之后再说话只显示名牌（画外音、隔着门说话、电话里的人也一样）。没有进出标注的人一开场就在。下一轮导演会看到上一幕结束时谁还在场。还没整理完的轮次沿用上一轮结束时的站位。
- **人物**：说话的人亮起、其余人退后；旁白描写某人的动作时也会让那人换表情。立绘按这一轮的衣服、长期状态和这句的情绪挑差分（见[立绘与情绪差分](#立绘与情绪差分)）；一张都还没画的人物画成剪影，发型、发色、马尾双马尾都按外貌档案来。
- **演出**：十六种漫画符号（爱心、怒筋、汗滴、闪光、惊叹、阴云、音符、Zzz、灵光、心碎、叹气、眩晕、燃起、红晕、开花、无语），各有自己的小动作；镜头推近 / 拉远 / 平移 / 倾斜 / 震动 / 闪白 / 红闪；短信 / 信件 / 便条 / 报纸 / 终端 / 告示 / 日记 / 卷轴八种情境卡片；十一种天气粒子（雨、暴雨、雪、樱花、落叶、萤火、余烬、浮尘、光斑、星空、雾）。
- **声音**：导演选的配乐交叉淡入淡出，右上角显示正在放的曲名。角色说话有打字音，16 种音色（清亮铃音、温柔气声、低沉男声、8-bit、打字机……），都是现场合成的、不占文件；每个角色可以在「人物志 → 档案」里挑音色、调音高，没挑的按性别自动分，同一局里先登场的先挑、后来的尽量不撞。设置的「声音」页能逐个试听音色，给旁白单独定一个；重音落地、怒吼拍桌、刺中要害、灵光一闪和界面音每种有 5 个版本可换，也能换成自己的音频文件（mp3、ogg、wav 等，最大 5 MB）。
- **阅读**：逐字显示、自动、快进、回想（滚轮或 L）、隐藏界面（H）、每局记住读到哪里。键盘：空格 / 回车 / → 翻页，← 后退，A 自动，Ctrl 快进，Esc 回到聊天。
- **选项**：一轮的最后给出导演写的选项和自由输入框。选好后文字会填进 Tavern 的输入框（同时复制到剪贴板），剧场收起，下一轮写完会自动回来接着演。
- **皮肤**：星穹（默认）、樱色、水墨、夜金、赛博五套。手机竖屏自动换布局。

## 台词演出

像逆转裁判那样，一句话怎么「说出来」本身就是表演：

- **标点停顿**：逗号短停、句末长停、省略号一个点一停（跟着文字速度等比缩放）；打字音和立绘口型也在停顿处停下。
- **演法**：导演给台词标一种演法；没标时按字面推断（几个感叹号是激动，生气加感叹号是怒吼，结巴或省略号多是迟疑）。

  | 演法 | 怎么说出来 |
  |---|---|
  | 威压 | 一个字一个字砸下来，打字音低沉 |
  | 激动 | 连珠炮，每个感叹号震一下对话框 |
  | 怒吼 | 几个字一块蹦出来、字放大，一开口就震屏、闪白、拍桌声 |
  | 迟疑 | 说说停停，省略号拖得更长 |
  | 低语 | 字小一号、淡一点，打字音轻 |
  | 崩溃 | 忽快忽慢、字一直在抖，红闪、震屏、刺耳的一声 |

- **重音**：导演挑出一句里最要命的几个字（指认的名字、关键证词、告白的那句话），先顿一拍，再一字一顿地落下、标红，落地那一下震屏或响一声。
- 漫画符号是灯泡（灵光一闪）时响一声「叮」。落字音效有自己的开关和音量（设置 →「声音」），每种都能换版本或换成自己的文件；系统设了「减少动态效果」时不震不闪。
- **逆转式立绘**（实验）：一张立绘差分挂了素材包（`sprite.json` + 呼吸帧 + 眼睛 / 嘴巴差分贴片，格式见 `lib/aa-sprite.js`）时，剧场在画布上分层画：呼吸、随机眨眼，嘴跟着上面的节奏开合（威压一字一张、怒吼张大、低语只半张）。导入：人物志 → 点开某个情绪的立绘 →「导入素材包」，选素材包所在的文件夹；这张差分的图会换成素材包的第一张呼吸帧（贴片是照它的坐标做的），格子上标「动」，不想要了点「取消动态」。只有挂了的那个情绪会动，别的情绪还是静态图；之后重画或上传这张差分会把素材包拿掉。素材包现在还不会自动生成；预览里可以用 `--aa-demo` 直接看效果（见「预览与截图」）。

插画分两步：导演只挑「画哪个瞬间、谁入画」，提示词由后台的**插画分镜师**另写。分镜师读人物卡、世界书、此前的全部剧情、这一轮按单元编号的正文、入画的人的档案（固定外貌、此刻穿的衣服和衣橱、长期状态、临时状态），以及这一局已经画过的几张图的提示词，同一轮的几张一次写完。写法参照柏宝绘给 NovelAI V4.5 / V5 定的那套规范，提示词是自己重新写的：

- **Base + 每人一个角色块**：Base 只写整张画面共有的（人数、时代与地点、器物、景别、光线、色调、多人之间的互动），某个人的外貌、衣服、身体状态、表情、视线、动作只进他自己的块。NovelAI V4 起每个块单独发（char_captions），别的渠道合并成一段。
- **人名不发**：块上的名字只用来对档案。出图前插件按名字把档案里的固定外貌补到这个人的块最前面（`1girl` 换成 `girl`，人数只在 Base），再把混进 tag 和描述里的人名删掉或换成 the girl / the boy；Base 没写人数就按块的性别补上。同人角色的身份 tag（`hatsune miku (vocaloid)`）保留在第一位。
- **表情要活、视线必写、动作写完整**：一个情绪词配一两个面部细节和一个肢体语言；视线跟着注意力走，不默认看镜头；及物动作写清手里拿着什么、落到哪，两人之间的动作用 `source#` / `target#` / `mutual#` 标出谁施谁受。
- **衣服写成指纹**：每套衣服 3～5 个 tag（款式 + 主色或花纹 + 一两个部件），同框两人撞了类别就分开主色；导演给新衣服建档时也按这个写。
- **分阶段的身体状态和防串**：怀孕按 0～4 阶段写；生图模型爱把一个人的醒目状态串到同框的人身上，所以没有这个状态的人在自己的块里写 `-1::pregnant::` 这类负权重。权重统一写成 NovelAI 的 `数字::tag::`，发给 SD 时换成 `(tag:1.2)`，旧版 NovelAI 换成括号，不认权重的渠道去掉数字，负权重只留在 NovelAI V4 起。
- **把文字补成一张画**：每张一个景别、一个光源、一个色调；先定这一局的时代和地域，落成时代 tag、两三件时代器物和合乎时代的光源，后面的图沿用；但不借时代感往画面里添正文没有的人和事。
- **画幅**：单人、站姿、特写、两人贴近写竖版，横向铺开的互动、群像、远景写横版，拿不准写竖版。剧场里竖图会摇镜展示全貌，聊天里竖图整张显示。
- **动笔前的清单**：状态账本（每个人此刻穿什么、带着什么状态）→ 时代锚 → 每张图的人物、景别、表情视线、动作、衣服、防串 → 自查。支持思考的模型在思考里过一遍，过程在导演日志里看得到。

鉴赏里的「改词」可以直接改 Base、画面描述、每个人的块（加人、删人）、画幅和种子，以及剧场里显示到哪一句，或者写一句「改成雨夜」让分镜师带着现在的提示词改写，看过草稿再重画；「当前版本实际发出的提示词」里能看到补完外貌、删掉人名后真正发出去的 Base 和每人一条。聊天里每条消息下的「🎬 配一张」也走分镜师：指定了段落就画那一段，没指定就让它挑这一轮最值得画的瞬间。分镜师写不出来时，按场景和档案拼一份保底。系统提示词可以在设置 → 导演里整段换掉。

## 立绘与情绪差分

![人物志：同一套衣服下的情绪差分](docs/screenshots/30-cast-variants.webp)

- **同一个人，同一个种子**：每个角色有一个固定种子（默认按名字算出来，人物志 → 档案里可以改，也可以 🎲 重抽），这个人所有的立绘都用它画，脸和画风更稳。
- **立绘设计师**：立绘的提示词交给后台模型来写，不是机械拼接。它先读人物卡、世界书、到这一轮为止的全部剧情、角色档案和这身衣服已经画好的立绘，再给这个人一次写一批差分。资料长度跟导演一样默认 1000000 字，模型窗口装不下时先从最早的剧情删起。固定外貌每张写法一致，表情和姿势按这个人此刻在剧情里的处境去演。它读了多少、写了什么，导演日志里有一条「立绘 · 名字」；模型不可用时按档案拼一份保底。
- **差分按「服装 × 长期状态 × 情绪」分**：导演整理剧本时会记下每个人穿什么（校服、睡衣、冬季制服……）和长期状态（怀孕、骨折打着石膏、变身……），换装和状态都从发生那一轮起生效。立绘先按「这一身加这些状态」分组，组里再按情绪分。湿身、手里拿着东西这类临时状态只进插画，不进立绘。还没画好的差分，先用同一身衣服里最接近的一张顶上，不会去借别的衣服的图。
- **情绪库**：导演给每句台词标情绪。库里没有贴切的词，它会自己造一个最合适的中文短语，可以是复合情绪，比如「带着烦躁思考」「苦闷地表白」「害羞地强装镇定」。新词连同一句神情描述加进情绪库，立绘设计师之后就照它画差分。情绪库所有对局共用，在人物志 → 情绪库里可以改描述、删掉，也可以自己加。
- **自己动手**：点任意一格差分，可以看这张的 tag 并修改，然后「让设计师重写并重画」「按这些词画」，或者上传自己的图。衣橱里可以改每套衣服的 tag、换穿哪一套、加减长期状态。

## 补图

当时没填 Key、关着自动出图、出图失败，或者画到一半 DSH 重启了，错过的图都可以补：

- 聊天里场景卡上的「补图」：只补这一轮。
- 鉴赏里的「补齐缺的图」：补整局的插画、背景和立绘差分。
- 人物志里的「补齐所有立绘」，以及每个人的「补齐剧情里用到的差分」：把剧情里这个人每一身衣服下用过的情绪都画齐。

已经画好的不会重画。前两个跟着设置走，关掉的背景、立绘、情绪差分不补；人物志里的两个按钮是你点名要的，照补。被重启打断的图会标成「中断了」，点一下就能重画。

## 柏宝绘的那一套

生图部分按 ST-BaiBai-Image（柏宝绘）的思路重新实现：

- **角色外貌库**：有名字的角色第一次出场自动建档。插画分镜师的角色块只写名字，出图前插件把档案里的固定外貌补进去（自己写的提示词里用老写法 `@林岚` 也认），所以同一个人每张图长得一样。
- **外貌时间线**：剪了头发、换了制服这种永久变化，从发生那一轮开始生效，之前的轮次重画时仍用旧外貌。湿身、包扎这类临时状态单独记，解除时清掉，不污染档案。
- **改动日志与回滚**：AI 对档案的每次改动都记在「档案变更」里，可以一键回滚。
- **全局角色**：把一个人「提升为全局」后，所有存档共用这份档案，AI 不再改它；也可以复制回本局再改。
- **画师串与质量词**：内置几套画师串，也能存自己的；质量词、负面词按模型分别设置。
- **CG 队列与版本**：出图排队、可取消，重画保留历史版本，随时切回旧版本。
- **分人提示词**：插画按柏宝绘的 NovelAI V4.5 / V5 写法写成 Base + 每人一个角色块，见上面的[插画](#插画)。
- **改词**：在鉴赏里打开任意一张图，可以直接改 Base、每个人的块、负面词、横竖构图和种子，或者让分镜师按你的一句话改写，再看最终发给模型的完整提示词。
- **立绘与表情**：登场自动画立绘，剧情用到新情绪时自动补差分，人物志里可以逐张重画、改词或上传。这部分比柏宝绘走得更远，见上面的[立绘与情绪差分](#立绘与情绪差分)。
- **生图渠道**：
  - NovelAI：官方接口，也可以加多个中转地址来回切换。内置 V5 Full / Curated、V4.5、V4、V3 等模型，官方出了新模型直接手填 ID；采样器、步数、提示词引导、引导缩放（Prompt Guidance Rescale）、噪声调度、Variety+ 可调。V5 可以给立绘开**透明底**（默认开），立绘站在场景里不带白底。
  - ComfyUI：简单模式选 checkpoint 即可；高级模式导入 API 格式的工作流 JSON，用 `%prompt%`、`%negative%`、`%width%`、`%seed%` 这类占位符接参数。
  - OpenAI 兼容的图片接口（gpt-image-1 等）。
  - Stable Diffusion WebUI（A1111 / Forge）：可以选底模、采样器和调度器，只对插件的请求生效。

  ComfyUI、WebUI 和 OpenAI 兼容接口的模型 / 采样器列表直接从服务器实时读取，跟着你那边的更新走；NovelAI 没有公开的模型列表接口，所以用内置列表加手填。每个渠道都有「测试连接」；种子可以固定（-1 为每张随机），鉴赏里改词时还能给单张指定种子。

## 隐私与密钥

- API Key 只存在宿主这一侧：优先放进 DSH 的凭据服务，没有凭据服务时存在插件数据目录下权限为 0600 的 `secrets.json`。浏览器只能看到「已填写」，拿不到 Key 本身。
- 插件只写 `$DSH_HOME/flowgal/`（设置、每局的场景脚本与人物档案、生成的图片、你导入的音乐），不读写 Tavern 自己的数据目录，也不给 Tavern 打补丁，只用公开的插件接口。
- 皮肤字体按需从 jsDelivr 加载官方发布的 npm 字体包（`@fontsource/*`、`lxgw-wenkai-webfont`），不随插件打包。连不上 jsDelivr 时，在设置 → 外观与演出里把「字体地址」改成 `https://unpkg.com/` 或自己的镜像（路径结构和 jsDelivr 的 `/npm/` 一样）。

## 实现说明

- 宿主半边：`lib/`。`clean.js` 在切单元前剥掉思考、变量更新、网页外壳和装饰（模型写 HTML 时按结构拆开），`segment.js` 把正文切成旁白 / 台词 / 心声单元；`director.js` 和 `prompts.js` 负责导演提示词和结果校验（含选曲）；`engine.js` 管排队、出图、补图、挂载到正文；`cast.js` 是外貌库（固定外貌、衣橱、长期状态的时间线），`look.js` 是「这一身」的键和立绘挑选（前后端共用），`staging.js` 按导演标的登场 / 退场算出每一句谁在台上（剧场和导演共用），`illustrator.js` 是插画分镜师（以及出图前补外貌、删人名、补人数），`sprites.js` 是立绘设计师，两者共用 `writer.js` 里按模型窗口裁剧情、重试、补写漏项的流程，`emotions.js` 是情绪库；`music.js` 是曲库，`music-sidecar.js` 是描述文件格式（前后端共用）；`image/` 是四个生图渠道。
- 浏览器半边：`src/client/`，打包成 `client.js`。React 由 DSH 提供，不打进包里。漫画符号是 `src/client/theater/symbols.js` 里自己画的 SVG，动效在 `styles/theater.css`。
- 功能参考了 [bigmalove/galgame](https://github.com/bigmalove/galgame) 和柏宝绘（ST-BaiBai-Image），代码、样式和素材全部自己编写，没有复制这些项目以及 DSH Tavern 本身的代码、样式或素材。
